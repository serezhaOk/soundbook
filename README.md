# Soundfall — прототип

Музыкальная игрушка-«водопад»: сверху из эмиттера падают ноты-шарики,
ты закрашиваешь ячейки сетки цветными «полями», и каждый цвет по-своему
взаимодействует с шариком — физикой и звуком.

## Запуск

```bash
npm install
npm run dev
```

## Цвета-эффекты

| Цвет | Эффект | Звук |
|---|---|---|
| 🟣 Желе | шарик вязнет, почти нулевая гравитация, медленно выплывает | эволюционирующий FM-дрон, пока внутри |
| 🟡 Батут | упругий отскок (единственный «твёрдый» цвет) | щипок с огромным реверб-хвостом |
| 🔵 Центрифуга | закручивает по спирали с ростом амплитуды и выплёвывает | delay-арпеджио вверх на каждом витке |
| 🟢 Арпеджиатор | пролетает насквозь с лёгким торможением | зиппер: ретриггер нот вверх по гамме |
| 🩷 Сплиттер | шарик делится на два (до 2 поколений) | хрустящий distortion-панч |

## Управление

- Свайп по экрану — красить ячейки выбранным цветом (20×20 px).
- Ластик — стирает области 4×4 ячейки.
- Кнопка play/pause — старт/пауза падения нот.
- Шарики несут ноты пентатоники, поэтому всё звучит консонансно.

## Стек

matter-js (физика) + Tone.js (синтез и эффекты) + Vite, vanilla JS, canvas.
