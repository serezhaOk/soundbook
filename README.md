# Soundfall — прототип

Музыкальная игрушка-«водопад»: сверху из эмиттера падают ноты-шарики,
ты рисуешь пальцем физические преграды, и каждое столкновение играет
ноту. Тип преграды задаёт эффект звука.

## Запуск

```bash
npm install
npm run dev
```

## Как играть

- **Тап по экрану** — включает звук (требование браузеров).
- **✏️ Рисовать** — веди пальцем/мышью, чтобы создать преграду-отрезок.
- **✋ Двигать** — перетаскивай преграды и сам эмиттер (кружок сверху).
- **🗑️ Удалять** — тапай или веди по преградам.
- **Слайдер** — темп появления шариков (BPM).
- **Типы преград**: белая — чистая нота, голубая — feedback delay,
  красная — bitcrush.
- Шарики несут ноты пентатоники по кругу, поэтому любой «водопад»
  звучит консонансно.

## Стек

- [matter-js](https://brm.io/matter-js/) — 2D-физика
- [Tone.js](https://tonejs.github.io/) — синтез и эффекты (Web Audio)
- Vite, vanilla JS, рендер на canvas
